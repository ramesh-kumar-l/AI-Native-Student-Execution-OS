# 53 · Postmortems

> Blameless writeups of incidents — anything that broke trust, broke reliability, or surprised us in a costly way.

**Format:** `YYYY-MM-DD-short-title.md`, structured as:

```markdown
# <Incident title>

- **Date:** YYYY-MM-DD
- **Severity:** SEV1 | SEV2 | SEV3
- **Status:** Open | Closed
- **Author:** <name>

## Summary
One paragraph: what happened, impact, duration.

## Timeline
Bullet timeline with timestamps.

## Root cause
The actual cause, not the proximate symptom.

## What went well
What we did right that we want to keep.

## What went poorly
What needs to change.

## Action items
- [ ] Concrete fixes with owners + due dates.

## References
Code links, ADRs, related risks in `43-risks.md`.
```

Blameless: postmortems describe systems, not individuals.
