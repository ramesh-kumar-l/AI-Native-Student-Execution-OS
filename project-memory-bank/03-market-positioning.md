# 03 · Market Positioning

## Who this is for (initial PMF target)

**AI-native engineering students and early-career builders, ages ~18–28**, who:

- Use AI tools daily but feel "tutorial-rich, capability-poor."
- Have intent to ship projects but stall on execution discipline.
- Already live in VSCode (or a VSCode-family editor).
- Care about portfolio / employability, not just learning for its own sake.

This is the **wedge audience**. Adjacent audiences (bootcamp students, self-taught devs, designers, technical founders) come after PMF is proven here.

---

## Who this is NOT for (yet)

- Casual learners with no shipping intent.
- Non-technical creators (designers, writers) — possible later but not the wedge.
- Enterprise teams — institutional features come post-PMF.
- Researchers wanting an academic notebook tool.
- People looking for a chatbot.

Being clear about *not yet* keeps us from chasing surface area before depth.

---

## Category we sit in (and how we differ)

| Adjacent category | What they do | Why we're different |
| --- | --- | --- |
| AI chatbots (ChatGPT, Claude, Gemini) | One-shot conversation | We have **persistent project + capability memory** and live in the workflow |
| Code copilots (Copilot, Cursor, Continue) | Inline code generation | We don't generate code — we **sense workflow** to extract capability signal |
| LMS / courseware (Coursera, edX) | Content delivery | We don't deliver content — we help **execute on intent** the user already has |
| Project mgmt (Notion, Linear, Trello) | Task tracking | We **plan from goals + AI mentorship**, not just track tasks |
| Productivity OSs (Notion AI, Mem, Reflect) | Notes + AI on top | We're **execution-first**, not capture-first, and offline-first by default |

The product's defensible position is the **intersection** of: persistent cognition memory + workflow sensing + mentor + capability tracking. No competitor occupies all four.

---

## Positioning statement (draft)

> For AI-native builders who want to stop consuming tutorials and start shipping capability, the **AI-Native Student Execution OS** is a desktop + VSCode execution layer that tracks what you actually do, mentors you in context, and remembers your trajectory — turning learning into capability and capability into employability. Unlike chatbots and copilots, it owns the workflow loop, owns the memory, and runs without the cloud.

(To be refined as we test wedge messaging.)

## Distribution strategy (early)

We deliberately do not write detailed marketing here yet; PMF first. Initial channels under consideration:

- Builder Twitter / Bluesky communities
- AI-native student communities (Buildspace-adjacent, hackathon communities)
- VSCode marketplace (the extension itself is a distribution vector)
- Open-source positioning of the local-first engine

Channel choices will be decided post-Phase-0 once the product has something to show.
