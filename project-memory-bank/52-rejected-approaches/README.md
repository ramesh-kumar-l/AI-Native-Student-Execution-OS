# 52 · Rejected Approaches

> Things we considered and chose **not** to do, with reasons. Saves future contributors from re-litigating settled questions.

**Format:** one file per rejected approach:

```markdown
# <Approach title>

- **Date considered:** YYYY-MM-DD
- **Context:** what we were trying to solve

## Approach considered
## Why we rejected it
## What we did instead
## Conditions under which we'd reconsider
```

A rejection is **not permanent** — the last section invites future revisitation when conditions change.
