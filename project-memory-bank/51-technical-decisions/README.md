# 51 · Technical Decisions

> Smaller-than-an-ADR decisions that still merit a written rationale. Use this when the decision affects only one subsystem and doesn't warrant a numbered ADR.

**Format:** one file per decision, kebab-case filename. No numbering. Each file:

```markdown
# <Decision title>

- **Date:** YYYY-MM-DD
- **Scope:** <which subsystem / file / module>

## Context
## Decision
## Notes
```

If a technical decision grows in importance, promote it to an ADR and link from here.
